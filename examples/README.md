# examples - 가상 상품과 스타일 팩 시안

## 공개 배포 범위

최종 이미지, 비교용 후보 이미지, 프롬프트, 검수 요약과 구조화된 결과를 배포한다.
원시 에이전트·이미지 제공자 세션 로그(`.log`, `.jsonl`, `*-stdout.txt`)는 로컬에만
보존하며, 아래 QA 문서가 인용하는 해당 경로는 공개 저장소에 포함되지 않는다.
기준 예제의 간결한 테스트·적용 결과 로그는 `.gitignore`의 명시된 예외만 포함한다.
세션 파일 경로와 해시는 출처 추적용 기록이며 실제 제품·인증의 증거가 아니다.

## 메인 예시 3종: v0.4에서 시작한 역사적 산출물

- [풍기골 홍삼 데일리스틱](punggi-red-ginseng-stick/)
- [광양 매실 젤리](gwangyang-maesil-jelly/)
- [제주 녹차 카테킨](jeju-greentea-catechin/)

각 폴더에는 원자료·intake, `cuts.md`(14컷), `legal.md`, 생성 이미지, `qa/`, `index.html`이 있다. **상품·브랜드·수치·인증은 모두 가상 설정**이다. 실제 판매·인증·심의·효능을 검증한 예시가 아니며 게시 준비 완료 자료도 아니다.

기존 QA는 v0.4에서 시작한 당시 산출물의 역사적 기록이다. **2026-09-06에 지적된 제품 정합성 8컷을 교체·검수했다.** 홍삼 C03·C10, 카테킨 C03·C05·C08·C10, 매실 C01·C07이 대상이며, 각 상품의 `qa/product-fidelity-grok-2026-09-06.md`에 실제 관찰과 이미지 해시를 남겼다. 앞선 `product-fidelity-2026-09-06.md`는 Codex 생성 실패 당시의 기록이다. 교체본은 원본 JPEG(`cNN.jpg`)이고 이전 PNG는 역사적 비교용으로 유지한다. 수정하지 않은 나머지 컷까지 새로 승인했다는 뜻은 아니다. 현재 렌더 결과는 `qa/render_check.json`, 변경된 매실 첫 화면의 독립 이해도 검사는 `qa/five-second-2026-09-06.md`를 확인한다. 가상 원자료와 미확정 법정·거래 조건은 그대로 남아 있다.

`qa/check_cuts.json`의 PASS는 텍스트·구조·출처 연결과 파일 존재 검사 범위다. 이미지 내용 검수와 렌더·5초 테스트, 실제 법정/거래 조건 확인은 별도다. [검증 계약](../skills/sangse/references/verification.md)과 [정량 출처 계약](../skills/sangse/references/numerical-provenance.md)을 따른다. 남은 자료나 교체 대기가 있으면 게시 준비는 미완료다. 가상 예시는 이 작업이 끝나도 실제 판매용으로 검증됐다고 표시하지 않는다.

## 스타일 팩 비교

[style-pack-variants/](style-pack-variants/)의 6종은 이미지 없는 카피 전용 시안이다. 각 폴더에 독립 입력 사본이 있으며 팩별 시퀀스·배경·정렬을 비교할 수 있다.

## 최신 기준 예제

[또박 손글씨 클래스 기준 예제](reference-offer-first/index.html)는 `offer-first` 팩의
11컷 이미지와 HTML, 실제 Codex 윤문·승인 해시, 독립 리뷰 4종, 최신 렌더 검증을
갖춘 가상 시연이다. [입력 출처·스코어카드](reference-offer-first/README.md)에서
기존 가상 입력과 기준 예제용으로 추가한 학습 시간 가정을 구분한다.
자동 검사 fail/warn 0, 고객 리뷰 8/8, 390/860px 렌더와 첫 화면 이해도 3/3을 확인했다.
실제 판매용 검증이나 결제 기능을 갖췄다는 뜻은 아니다.

현재 컷 시트 계약은 10~20컷, 전체 템플릿은 44종이다. 예시의 14컷이 모든 팩의 필수 장수를 뜻하는 것은 아니다.
